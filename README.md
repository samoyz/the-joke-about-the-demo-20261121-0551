# The joke about the demo

A one-line joke about working beside an AI coding agent, written by a program.

## The joke

> My AI agent fixed the demo crash, then proved the fix by crashing the app somewhere completely new.

## How it works

`main.ts` (Node 22, standard library only) writes the joke to `/output/entry.txt` as UTF-8 text.

```sh
node main.ts
```
